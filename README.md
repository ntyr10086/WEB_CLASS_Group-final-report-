# 災變大作戰：災難救援隊

SDG 13 氣候行動・2～4 人即時合作的 2D 像素救災遊戲。
Flask + Flask-SocketIO（WebSocket）+ MongoDB + LangChain/OpenAI + Phaser 3。

## 玩法

畫面上方會跳出「災情單」，每張都有倒數。照著需求準備工具或加工物資，衝到現場治災：

| 災情 | 要準備什麼 | 現場怎麼處理 |
| --- | --- | --- |
| 堤防破洞 | 空袋 → 到沙堆按住裝沙 | 放 3 包沙包 |
| 排水溝堵塞 | 耙子 | 按住清淤；撈出的淤泥送垃圾車有額外金幣 |
| 電箱冒火花 | 絕緣手套 | 按住拉下電源（沒戴手套靠近會被電） |
| 民宅淹水 | 馬達＋水管放上工作台 → 按住組裝成抽水機 | 放下抽水機，自動抽水 |
| 居民受困 | 救生圈 | 交給居民，帶他走到避難所 |
| 大樹倒下 | 斧頭 | 按住劈開（樹會擋路） |

- 災情超時：扣一顆愛心、水位上升。愛心歸零或水位到頂就失敗。
- 撐過三分鐘就過關，依金幣給星星。
- 手上一次只能拿一樣東西，可以丟在地上給隊友接力。
- 耙子、手套、斧頭用完會自動歸還；沙包、救生圈、抽水機交出去就消失。
- 畫面沒有閃光效果（打雷只有聲音），危險狀態只用顏色提示。
- 天氣分小雨 → 颱風眼 → 暴雨，暴雨時災情最多最急。

## 三種氣候災難（每局隨機）

每局開場隨機抽一種災難（不會連續兩局一樣）。三種災難的**倉庫道具、加工站、救災做法和防災知識都不一樣**；新手教學固定是颱風。

| 災難 | 招牌玩法 | 災情與做法 |
| --- | --- | --- |
| 颱風淹水（水位） | 沙堆裝沙包、工作台組抽水機 | 堤防破洞：沙包×3／排水溝：耙子按住→淤泥送垃圾車／電箱：戴手套按住（空手會被電）／民宅淹水：抽水機／受困：救生圈帶去避難所／倒樹：斧頭按住 |
| 熱浪野火（火勢） | 水井打水、接力提水；滅火器兩人一起噴 | 山火逼近：滿水桶×3／乾草堆積：鐮刀割出防火帶／電線過載：**空手**按住拔插頭／民宅起火：**兩人**拿滅火器一起按住／居民中暑：**飲用水＋冰毛巾**都送到再帶去避難所／枯樹倒塌：斧頭→枯枝送清運車 |
| 豪雨土石流（土石） | 工作台做擋土柵；空手通知撤離；兩人一起挖 | 土石滑落：木樁＋鐵絲網做擋土柵×2／溝渠塞泥沙：鏟子→泥沙送清運車／電箱泡泥：拉警示帶（空手靠近會被電）／住戶撤離：**空手**按一下通知、帶去避難所／居民受困：**兩人**拿十字鎬一起挖／落石擋路：鐵鎚→碎石送清運車 |

- 災難資料（名稱、畫面、台詞、新聞、知識）與玩法（`KITS`：倉庫道具、加工站、每個災情的做法）都在 `disasters.py`
- 做法的種類：交出道具（可要求次數）、按住（可指定空手、要幾人一起）、交出後自動進行、帶居民去避難所、交齊多樣道具
- 知識庫中熱浪、土石流的條目用 `heatwave:drain` 這類 tag 檢索

## 劇情章節（遊戲想傳達的事）

每局分三章，跟著天氣階段走；章節開始時由角色交代一個「劇情任務」，右上角會顯示任務和進度，任務要處理的災情單會有 ★。

| 章節 | 想傳達的事 | 颱風 | 熱浪 | 土石流 |
| --- | --- | --- | --- | --- |
| 第一章 | 平時準備 | 先清通排水溝 | 先割乾草、清出防火帶 | 先清通溝渠 |
| 第二章 | 鄰里互助 | 趁雨停救人、抽水 | 照顧獨居長輩 | 挨家挨戶通知撤離 |
| 第三章 | 氣候變遷 | 守住堤防 | 一起滅火 | 合力救援 |

- 做到：角色說出成功的結果，加金幣
- 沒做到：角色說出後果，而且計量條會上升（沒準備好，之後就更危險）
- 結算畫面有「這局的故事」，列出三章的結果；鎮長的話也會提到哪一章沒做到

## 帳號與好友（可選，不登入也能用訪客玩）

- 大廳右上角「登入／註冊」：帳號名就是遊戲暱稱（2～10 字），密碼至少 6 字，只存雜湊（werkzeug）。
- 登入後暱稱鎖定；訪客不能使用已註冊的名字。
- 帳號的戰績只算「登入後玩的局」（存在 `users.stats`，紀錄用 `game_records.players.account` 查），以前用同一個暱稱當訪客玩的紀錄不會算進來。
- 「隊員證」裡有：
  - 我的紀錄：場數、撐住場數、最高金幣、最多星，加上最近 10 局（災難、結果、隊友）
  - 好友：每個帳號有 6 碼好友碼，輸入朋友的好友碼就互相成為好友；可以看好友在不在線、在哪個房間（一鍵加入）、好友的最近紀錄
- 登入狀態用 Flask session cookie（30 天），Socket.IO 連線時讀 session 知道是誰。

## 響應式與手機

- 遊戲畫面依視窗大小等比縮放（3:2），筆電、小視窗、平板都能完整看到；上方的災情單與數值也跟著縮放。
- 小畫面會自動精簡：災情單只留名稱和倒數，完整做法看「?」救災手冊。
- 觸控裝置會出現虛擬搖桿和「拿・放」大按鈕（按住＝處理災情），手機橫放最好玩。

## 新手教學

第一次玩一定要先完成新手教學，才能建立或加入隊伍（完成紀錄存在瀏覽器裡，第一次玩不能跳過）。之後在大廳可以「再玩一次新手教學」。

教學關：32 個步驟，一次只做一個動作（走到哪、按一下或按住），帶過六種災情。
教學中災情不倒數、不扣愛心，畫面上有箭頭指向下一個要去的地方，隨時可以按「跳過教學」。

正式遊戲中，角色頭上也會即時顯示「現在按空白鍵會做什麼」，例如「空白鍵 拿耙子」「按住空白鍵 裝沙」「帶去：排水溝堵塞」；
手上拿著某個災情需要的東西時，那個災情的需求泡泡會放大。

## AI（LangChain）

| 功能 | 說明 |
| --- | --- |
| 開局劇本 | 生成這局的颱風名字、新聞快報與小鎮弱點，決定各類災情的出現權重 |
| 災難導演 | 依戰況（愛心、水位、進行中的災情）從候選清單挑下一個災情，並寫居民求救台詞 |
| 災後檢討 | 依這局實際發生的災情，從 MongoDB 知識庫檢索防災知識再講評（簡化版 RAG） |

`llm.py` 用 LangChain 把 OpenAI 和 Ollama 包成同一個介面，由 `.env` 的 `AI_PROVIDER` 決定：

| AI_PROVIDER | 行為 |
| --- | --- |
| auto（預設） | 有 OPENAI_API_KEY 先用 OpenAI → 再試本機 Ollama → 都不行用規則版 |
| ollama | 只用本機 Ollama（課堂 ch7 的做法，免費、不用網路） |
| openai | 只用 OpenAI（Render 雲端版用這個） |
| off | 全部規則版 |

- 某一家失敗會自動換下一家；全部失敗就用規則版，遊戲不會卡住
- Ollama 強制 JSON 輸出（`format="json"`），伺服器啟動時先「預熱」把模型載進記憶體
- AI 只能從清單裡挑選，輸出一律驗證後才採用；玩家輸入不會進到 prompt
- `/api/ai/status` 看現在用哪一家、上次花幾毫秒；Ollama 晚開的話打 `/api/ai/status?refresh=1` 重新偵測

## MongoDB

| Collection | 內容 | 寫入時機 |
| --- | --- | --- |
| players | 暱稱、場次、勝場、治災數、最佳分數、最近稱號 | 每局結束（upsert + $inc + $max） |
| rooms | 房間代碼、房主、成員、狀態、這個房間玩過的紀錄 id | 建房 → 開始 → 結束 → 全員離開 |
| game_records | 結果、分數、每位玩家表現、事件日誌 events、AI 講評與引用的知識 | 遊戲結束先存，AI 講評好了再補上 |
| knowledge | 防災知識（topic、content、tags、source） | 啟動時若筆數和 `data/knowledge.json` 不同，自動重新匯入 |
| users | 帳號名、密碼雜湊、好友碼、好友名單、帳號戰績 stats | 註冊、加／刪好友、每局結束 |

- 遊戲中的位置、水位只放在伺服器記憶體，不會每幀寫庫
- 排行榜、災情統計用 aggregate（`$sort`、`$unwind`、`$group`）
- 沒設定 `MONGO_URI` 時改存記憶體，方便先測遊戲
- 改了 `data/knowledge.json` 之後執行 `python db.py seed` 重新匯入

## REST API

| 方法 | 路徑 | 功能 |
| --- | --- | --- |
| GET | /api/leaderboard?limit=10 | 排行榜 |
| GET | /api/records | 最近的遊戲紀錄 |
| GET | /api/records/{id} | 單局紀錄（含事件日誌、AI 講評） |
| GET | /api/players/{暱稱} | 玩家累積戰績 |
| GET | /api/stats | 所有場次每種災情成功／失敗次數 |
| GET | /api/knowledge?tag=electric | 防災知識庫 |
| GET | /api/ai/status | 目前的 AI 供應者與狀態 |
| GET | /api/health | 伺服器、資料庫、AI 狀態 |
| GET | /api/me | 目前登入的帳號 |
| POST | /api/register、/api/login、/api/logout | 註冊、登入、登出 |
| GET | /api/me/records | 我的戰績與最近 10 局 |
| GET / POST | /api/friends | 好友列表（含在線、房間）／用好友碼加好友 |
| DELETE | /api/friends/{名字} | 刪除好友 |
| GET | /api/friends/{名字}/records | 好友的戰績與最近 10 局 |

## 本機執行

```bash
python -m venv .venv
source .venv/bin/activate          # Windows：.venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env               # Windows：copy .env.example .env
python app.py
```

### 用本機 Ollama（不用 OpenAI Key）

1. 安裝 Ollama（https://ollama.com），下載模型：`ollama pull llama3.2:3b`
2. `.env` 設 `AI_PROVIDER=ollama`（或保持 auto、不填 OPENAI_API_KEY）
3. `python app.py`，終端機出現「使用順序：ollama → 規則版」「Ollama 預熱完成」就成功了

小模型中文偶爾會怪，可以改試 `qwen2.5:3b`（`ollama pull qwen2.5:3b`，再把 `OLLAMA_MODEL` 換掉）。

### 用 MongoDB

- 本機：安裝 MongoDB Community，`.env` 設 `MONGO_URI=mongodb://localhost:27017`
- 雲端：MongoDB Atlas 連線字串填進 `MONGO_URI`
- 啟動時出現「已連線 MongoDB」「已匯入 16 筆防災知識」，用 Compass 打開 `flood_rush` 資料庫就看得到四個 collection

打開 http://localhost:5000 → 建立房間 → 另一個分頁或手機輸入代碼加入 → 房主按「出發救災！」。
測試時想快一點：`GAME_TIME=60 python app.py`

## 操作

WASD／方向鍵移動；空白鍵拿・放・交付，處理災情要「按住」；Q 發出求救標記；H 打開救災手冊（所有災情的完整做法）。

畫面配置參考《Overcooked》：災情單（含簡化食譜）疊在左上，愛心、金幣、時間、水位在右上，鍵位提示在左下。

## 檔案

| static/js/main.js | 大廳、災情單 HUD、開場快報、結算 |
